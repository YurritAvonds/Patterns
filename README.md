# Patterns

Reference repository containing a number of design patterns and other concepts/structures. Intended as a source of inspiration and to be able to quickly grasp and try out (through corresponding unit tests) these concepts.

## Standard

The standard design patterns as documented on [Refactoring Guru](https://refactoring.guru/). Currently incomplete but more will be added over time.

* [Source](https://github.com/YurritAvonds/Patterns/tree/master/Patterns/Standard)
* [Unit Tests](https://github.com/YurritAvonds/Patterns/tree/master/UnitTests/Standard)

## Personal

Patterns and structures that I often use and are not strictly speaking a standard design pattern (even if they may be based off of them).

* [Source](https://github.com/YurritAvonds/Patterns/tree/master/Patterns/Personal)
* [Unit Tests](https://github.com/YurritAvonds/Patterns/tree/master/UnitTests/Personal)

Structures/concepts related to [FHIR](https://www.hl7.org/fhir/) and the creating/parsing of FHIR resources.

* [Source](https://github.com/YurritAvonds/Patterns/tree/master/Patterns/Fhir)
* [Unit Tests](https://github.com/YurritAvonds/Patterns/tree/master/UnitTests/Fhir)
